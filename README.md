## Travaux effectués

### Interface
Pour l'interface, chaque composant (Rivière, Terrain et Obj) a son propre panneau de réglage pour ses paramètres.

Vous pouvez décider, pour chacun des éléments, de les afficher ou non.

### Terrain
Pour l'interface, chaque composant (Rivière, Terrain et Obj) a son propre panneau de réglage pour ses paramètres.
- Décider d'afficher ou non le mode fil de fer.
- Afficher la texture du terrain.
- Si vous ne l'activez pas, le terrain sera dessiné selon le niveau de hauteur.
- Choix de la texture du terrain.
- Choix de la Height Map à appliquer sur le terrain.
- Choix d'afficher le terrain.
Vous pouvez décider, pour chacun des éléments, de les afficher ou non.

### Rivière
- Choix de la texture de la rivière
- Choix de la bump map à appliquer sur la rivière
- Choix d'afficher la rivière

### OBJ

- Choix de l'OBJ
- Choix d'afficher l'OBJ

#### Commande 
*Shift* + *Clic* glissé sur le canevas pour déplacer le soleil. 
*Ctrl* + *Clic* pour zoomer doucement.

## Bonus 

- Le terrain utilise Phong au lieu lambert.
